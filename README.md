## Backend Architecture

The applications follow a modular architecture with clear separation of responsibilities:

* **Routes** — API endpoint definitions
* **Controllers** — request handling and application logic
* **Services** — reusable external and business operations
* **Models** — database schemas and data access
* **Middlewares** — authentication, authorization and request processing
* **Database Layer** — MongoDB/Mongoose integration

This approach keeps applications **modular, maintainable, reusable, and testable**.

## Security

Sensitive configuration is managed through environment variables and excluded from version control.

```env
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
IMAGEKIT_PRIVATE_KEY=your_private_key
```

> Never commit credentials, API keys, database connection strings, or other sensitive information to version control.
